🎙️ Milo - AI Voice Assistant SaaS

Milo is a full-stack SaaS platform that allows website owners to build, customize, and embed a smart AI voice assistant into any web application in minutes. Built with React, Node.js, and the Groq API, Milo delivers ultra-fast, conversational voice interactions and smart website navigation.

✨ Key Features
⚡ Ultra-Fast AI Processing: Powered by the Groq API (Llama/Qwen models) for near-zero latency responses. Dynamic model resolution ensures 100% uptime by automatically selecting active models.

🗣️ Seamless Voice Interaction: Utilizes the Web Speech API for continuous speech-to-text recognition and natural text-to-speech playback.

🧭 Smart Voice Navigation: Users can navigate the host website simply by speaking (e.g., "Take me to the pricing page").

🎨 Custom UI Builder: Dashboard to fully customize the assistant's appearance (Dark, Light, Glass, Neon themes), personality, tone, and business context.

🔌 Plug-and-Play Embedding: Generates a simple <script> tag that clients can paste into their HTML to instantly add the assistant widget to their site.

📊 Usage Tracking: Built-in message limits, free/pro plan tracking, and API key management per user.
